new_paradigm branch - 10/27/26:
- Code organized as in the new_paradigm branch of GHOST: the solver,
  the initial conditions, the forcing and the time stepper are classes
  chosen at run time from `parameter.inp`.
- The grid and the FC-Gram continuation are read at run time, from the
  `grid` namelist.
- Compilation with CMake instead of `make`.
- Only the solver `HD` is kept, and FC-Gram continuations only in z.
- Support for GPUs with OpenMP offload and cuFFT/hipFFT (`fftp-gpu`).
- MPI calls with `mpi_f08`.
- Enstrophy in `balance.txt` includes the three components of the
  vorticity (J. Cullen & G. Marchetti).

v2.0 - 7/21/21:
- fcgram module moved from `pseudo` to `fftp` and it now incorporates
  all the required datatypes and helper functions.
- New module `boundary` to deal with boudary conditions for each field.
- Solvers renamed to reflect the bulk PDEs they are solving.
- Added new solver `MHD`.
- Poisson solvers for Robin and Dirichlet boundary conditions.
- Boundary (and divergenceless) diagnostic routines in
  `boundary` module.
- Added basic support for FC-Gram in y direction. More work needed
  before solvers with non-periodic boundaries in y are supported.
